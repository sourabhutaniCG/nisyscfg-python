# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

#### Unreleased
- Added
  - Python 3.14, Python 3.14 free-threaded (3.14t), and Python 3.15 support.
- Fixed
  - Dependency information IDs, versions, and titles are decoded as strings.
  - Native operations that return NULL details pointers now return empty detail strings.
- Changed
- Removed
  - Python 3.9 and Python 3.10 support.
